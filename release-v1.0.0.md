## 🚀 TechTalk v1.0.0 — Initial Release

The first public release of **TechTalk**, a mobile-first developer community platform built with Flutter.

---

### What's new
- 🔐 User registration & login with OTP email verification
- 📝 Short-form posts and long-form technical blogs
- 💬 Nested comments with @mentions and reactions (like, dislike, highlight)
- 👥 Follow/unfollow developers and personalized feed
- 🔔 Real-time notifications via Pusher
- ⭐ XP system with levels and expert badges
- 👤 Profile pages with social links and stats
- 🔖 Save, bookmark, and view tracking
- 🔍 Search and tag browsing
